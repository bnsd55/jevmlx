# Security Policy

## Supported versions

Only the latest release is supported with security fixes.

## Reporting a vulnerability

Do not open a public issue. Use GitHub Security Advisories: the
**Report a vulnerability** button on the repository's **Security** tab.
Please include the jevmlx version (`jevmlx --version`), macOS version and
chip, and a minimal reproduction.

We aim to respond within 7 days; fixes land in the next release.
